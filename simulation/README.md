# Simulation

The existing MATLAB/Simulink model will be added in the dedicated Simulink packaging stage.

The source project records a nominal six-degree-of-freedom model with cascaded control, motor dynamics, disturbances, deterministic sensor noise, three flight modes, yaw-aware position mapping and 3-D visualisation. Saved validation is reported for defined scenarios, but no executable model or validation evidence is included in Stage 1.

The model is not calibrated to the physical UAV and does not control it.
