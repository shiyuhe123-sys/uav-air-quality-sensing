# Reproducibility

The executable model package is under [`simulation/`](../simulation/README.md). It contains the canonical `.slx` model, its MATLAB-file parameter source, run scripts and assertion-based validation scripts.

## Recorded environment

Private development records identify MATLAB and Simulink R2024b on Windows as the original environment. Both packaged validation workflows were rerun successfully in that environment on 7 September 2026. Compatibility with other MATLAB releases has not been established.

The validation does not require the Simulink Test product. The source environment did not provide `sltest.testmanager`, so the included tests use deterministic simulations and explicit MATLAB assertions. The 3-D animation uses MATLAB graphics; project records state that Simulink 3D Animation and UAV Toolbox were not installed or required for that workflow.

## Run sequence

From the repository root in MATLAB:

```matlab
run(fullfile(pwd,"simulation","tests","validate_guidance_features.m"))
run(fullfile(pwd,"simulation","scripts","run_3d_visualization.m"))
run(fullfile(pwd,"simulation","tests","validate_3d_visualization.m"))
```

The visualisation validation consumes the output generated by `run_3d_visualization.m`, so those final two commands are ordered. Full instructions and individual entry points are in the [simulation README](../simulation/README.md).

The scripts create `simulation/outputs/` as needed. Generated `.mat` files, caches and video are excluded from Git because the committed model and scripts should reproduce them. The concise [package validation record](../simulation/docs/PACKAGE_VALIDATION.md) preserves the rerun outcome. Any later physical parameter must identify its measurement source, configuration and units.
