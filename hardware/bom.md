## Interpretation

The four-motor, 6S Tarot 650 configuration is the current recorded build direction. The current power module is the Holybro PM08-CAN; superseded component names and configurations are not part of this current BOM. Older alternatives, including superseded frame, battery and propulsion estimates, are not part of this current BOM. The approximate mass is not mixed with the older design estimates because it refers to the reported battery-included aircraft before the final payload is installed.

The component quantities are recorded as physically checked in the project record, but the public source photographs do not prove every quantity. A future as-built release should add a reviewed inventory, final payload configuration, exported parameters and metadata-cleaned photographs if those materials are suitable for publication.
